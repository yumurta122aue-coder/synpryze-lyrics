# Synpryze Lyrics

The helper app behind the Synpryze lyrics card.

1. Download **SynpryzeLyrics.exe** from the [latest release](../../releases/latest).
2. Double-click it. If Windows says "Windows protected your PC", click **More info → Run anyway**.
3. Play a song on Spotify, SoundCloud or YouTube and turn on the **Lyrics Card** in Synpryze's Lyrics tab.

It runs in the tray (music note; right-click to quit). It reads what is playing from the Windows media controls,
finds synced lyrics on [LRCLIB](https://lrclib.net) and only answers on your own PC (127.0.0.1).
